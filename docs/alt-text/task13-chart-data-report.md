# Task 13 — Grounded chart-label data extraction

Implemented local extraction of reviewer-verified, positioned numeric labels from Task 12 evidence, followed by a separate explicit confirmation of each label's data-value role. A numeric annotation starts as Unknown with a separate candidate interpretation; it becomes Label Exact only after an authorized reviewer confirms its role. No dataset is automatically approved.

## Supported behavior
- Printed numeric, negative, scientific-notation, percentage and Devanagari values in supported chart regions. The method transcribes visible labels, including labels on line, bar/column, grouped/stacked, scatter, histogram, pie/doughnut and area figures when present; it does not recover bar heights, stack segments, unlabelled points or pie angles.
- Source Exact, Label Exact, Image Estimated, Qualitative Only and Unknown are distinct contract classifications. This engine emits Label Exact or Unknown. Native Source Exact and Image Estimated capabilities are explicitly false.
- Native chart audit: PPTX graphic frames are counted but are not linked to extracted image occurrences; DOCX charts are skipped by existing image extraction/insertion. No workbook/chart XML from another occurrence is used.
- Task 12 fits remain candidate transforms with pixel extraction disabled. No zero origin, linear interpretation of logarithmic axes, pixel coordinates for marks, hidden/overlapping points or estimated precision are invented. Label boxes are explicitly separate from unknown visual-mark coordinates.
- Reviewer mappings use only this chart's existing legend labels, category labels and axes. Unknown mappings remain separate. Unit disagreement blocks an exact value; duplicate-position OCR is preserved and excluded from comparisons. Rounding is none and original strings are retained.
- When enabled in Accessibility Settings, comparisons use only confirmed label values within one series, axis and unit group. Numeric/date categories must be distinct and compatible before reporting increasing/decreasing/stability/local extrema. Categorical ranking uses visible values only. No causality or significance claims.

## Integration and persistence
- Existing generic accessibility-evidence table: chart_data immutable extraction versions and chart_data_review append-only label decisions. No new subject tables or migration.
- Existing durable advanced-analysis worker, cancellation and lease-fenced writes. Local processing has no model selection, metering or provider request. Parent chart/axes versions, actual source digest/frame, reviewed OCR and trend settings are rechecked before delivery.
- Review saves require both existing approve and update permissions, target update scope, optimistic version checks, request identity replay, source checks under the asset lock, and the existing asset audit. Numeric corrections go through OCR review rather than client-provided values.
- Routes: scoped chart/axes/data GET+POST; saved chart-data GET, reviewer POST and CSV export. The nested chart reference must match its axes parent. Tenant, asset, occurrence, evidence kind and completion state are bound server-side. Bodies and candidate counts are bounded.
- Existing inspector gains a compact original-image/selected-label overlay, table, series/category/axis selections, confirmation/rejection, warnings and immutable extraction history. Later decisions remain separate from the original snapshot. Changed source/labels are flagged as historical and the current-image overlay is hidden.
- CSV/copy uses the existing exporter and existing export permission. Every row retains source digest, evidence/version IDs, OCR and role-review references, exact/unknown state, units, warnings and unapproved dataset status. Formula protection now also covers leading whitespace/BOM before formula characters; Unicode and CSV quoting are preserved.
