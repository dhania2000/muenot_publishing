# Task 16 — Flowcharts, image tables, maps and mixed figures

Implemented on 2026-10-28 using the existing inspector and generic advanced-evidence pipeline. All structure, source positions, semantic roles and reading-order proposals remain candidates requiring human review.

## Reuse and supported structures
Existing category classification and Task 4 hierarchy/relationships identify eligible flowchart, table, map and mixed-content roots. Region taxonomy adds visible table cell/row/column bands and map route/area/landmark/orientation candidates. Existing OCR now accepts table-cell regions. This is a region taxonomy extension, not another OCR or image-analysis application.

Flowcharts preserve existing nodes, candidate start/end/process/decision/input-output roles, connectors, branch-label references and groups. Known flow direction requires compatible visible arrowhead evidence; a generic arrowless connector cannot establish directed flow. Unresolved endpoints/directions stay null/unknown. Source references, duplicates, panel isolation and label association through hierarchy or existing hints are validated. Candidate branch/cycle/unconnected-node findings are derived only from the saved visible connector graph, without hidden branches or a claim of semantic correctness.

Tables preserve existing table/cell/row/column references, cell coordinates, header candidates and proposed spans. This bounded engine supports at most 20 cells and 20 source bands per axis in a proposal. Grid positions require typed existing row/column bands, valid indexes/spans, compatible band positions and no overlapping grid slots. Missing boundaries keep positions null and spans unasserted rather than constructing a table from a spaced list. Merged-cell proposals require explicit source cell and band references and remain unverified. Larger or incomplete source tables receive partial-structure findings.

Cell values come only from compatible cell-scoped OCR or separately versioned corrections. No full-table OCR block is copied into every cell, no text is generated by the provider, and missing OCR remains unknown rather than blank/zero. Raw and corrected text retain independent source IDs, versions, review states and Unicode. A reviewed text transcription never verifies the table structure.

Maps preserve source title, legend, orientation/scale-label, route, area, landmark and label references. Results distinguish a schematic candidate from an unavailable/unknown georeference. No GPS coordinates, geographic identities, distance conversion, scale calibration, geocoding or route calculation are produced. Printed scale text stays literal evidence.

Mixed figures preserve source categories, parent groups, chart/scientific/flow/table/map subfigure identities and proposed sequences. Nested specialist roots are analyzed separately, keeping their children out of unrelated panel evidence. Existing Task 14/15 scientific and chart records remain separate; there is no graph-data or scientific-domain rewrite.
